# Suporte

## Onde buscar ajuda

- **Bug ou comportamento inesperado?** Abra uma [issue de bug report](../../issues/new/choose).
- **Ideia de funcionalidade?** Abra uma [issue de feature request](../../issues/new/choose).
- **Dúvida sobre como usar ou contribuir?** Use a aba **Discussions** do repositório, se
  estiver habilitada, ou abra uma issue com a label `question`.
- **Vulnerabilidade de segurança?** Não abra issue pública — siga o [SECURITY.md](./SECURITY.md).

## Antes de perguntar

1. Confira o [README.md](./README.md) e o [IMPLEMENTACAO.md](./IMPLEMENTACAO.md) — a
   dúvida pode já estar respondida ali.
2. Procure nas issues (abertas e fechadas) se alguém já passou pelo mesmo problema.
3. Se for erro ao rodar o projeto, inclua: sistema operacional, versão do Node
   (`node -v`), versão do Expo CLI, e o log de erro completo.

## Tempo de resposta

Este é um projeto de portfólio mantido no tempo livre dos mantenedores — não há SLA
garantido, mas issues bem descritas tendem a receber resposta mais rápido.
